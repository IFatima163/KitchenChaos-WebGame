# Kitchen Chaos
A 3D Single-player game built with Unity + C#.

## Features
- Order-list for what task to perform
- Correct or Incorrect order delivery check
- Veggie cutting area & bar for guidance
- Patty cooking bar to help with time management
- Bin to discard burnt patties and incorrect orders
- Clock for most orders in pre-determined time slots
- Options menu to manage sound and audio
- Music and in-game audio for better game-play
- Tutorial at the start of the run

## Tech Stack
- **Frontend:** Unity UI
- **Backend:** C#, Unity
